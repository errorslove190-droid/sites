P1 / PLATFORM-01 — Game Ready отправляется перед первым экраном

  • Доказательство: YG.boot вызывает loadingReady() на строке 3068. Только затем восстанавливает состояние и показывает экран; для новой игры startAcceptance отложен ещё на 100 мс, строка 3087. Загрузочный экран скрывает showScreen через hideGameLoading, строки 3216–3222, 3445–3450. В исходной модельной пробе журнал после завершения boot равен ['ready'], первый игровой экран ещё в очереди таймера.
  • Последствие: платформа получает сигнал готовности, пока игрок ещё видит загрузку. Game Ready должен соответствовать готовому интерфейсу.
  • Проверка: новая игра и все сохранённые фазы с debug-панелью; индикатор готовности меняется одновременно с первым интерактивным экраном, после исчезновения загрузки.
  • Подготовлено: единственный ready после показа UI, удаления загрузочного слоя и двух кадров отрисовки; поздно пришедший SDK получает ready, повторные переходы его не дублируют.

P1 / PLATFORM-02 — медленный SDK отключается навсегда; незавершённый init блокирует запуск

  • Строки: 2677–2708, 3063, 3224–3226.
  • Доказательство: при загрузке /sdk.js позже пяти секунд initSDK возвращается; повторного подключения нет. В пробе с появлением SDK на шестой секунде booted=true, ysdk=null. Обратный случай: YaGames.init() и getPlayer() ожидаются без верхнего предела; исчезновение загрузки на 12-й секунде не запускает игру.
  • Последствие: игра без рекламы/облака/платформенных событий либо пустой интерфейс. Путь /sdk.js выбран правильно для архива; проблема в управлении ожиданием. Актуальная схема загрузки.
  • Подготовлено: ограничено ожидание boot и player, подписка на события до запроса данных игрока, повторное подключение после поздней загрузки скрипта. Если пользователь уже играет локально, поздний SDK подключает рекламу и события, но не заменяет сохранение облачными данными посреди сеанса. Облако в таком сеансе остаётся отключённым до следующего нормального запуска; это явный компромисс против потери прогресса.

P1 / PLATFORM-03 — разные причины паузы снимают друг друга
