# style.md — паспорт стиля: портфолио Суюхана

Эстетика: **тёмная монтажная**. Экран как чёрный монитор в аппаратной: свет даёт только видео, интерфейс молчит. Один акцент — цвет выделенного клипа на таймлинии. Всё остальное — оттенки чёрного и волосяные линии.

## Палитра

| Токен | Значение | Где |
|---|---|---|
| `--void` | `#0a0a0b` | фон страницы |
| `--panel` | `#131316` | рамки превью, бегущая строка, ховер услуг |
| `--line` | `#26262b` | волосяные границы, разделители |
| `--line-2` | `#3a3a41` | границы вторичных кнопок, пунктир слотов |
| `--ink` | `#edece8` | основной текст (тёплый белый, не чистый #fff) |
| `--dim` | `#8e8e88` | подписи, лиды, служебное |
| `--acc` | `#ff4d1c` | **один** акцент: кнопки, плейхед, цифры, курсив в заголовках |

Акцент — только для действия и для одного слова в заголовке. Два акцентных пятна рядом — ошибка.

## Шрифты

- Заголовки, цифры, таймкод: **Unbounded** 500/700 (кириллица есть).
- Текст: **Onest** 400/500/600 (кириллица есть).
- Фолбэк: `'Segoe UI', system-ui, sans-serif`.
- Запрещены: Inter, Geist, Roboto, Lato, Montserrat, Open Sans, Plus Jakarta Sans, Space Grotesk.

## Размеры и ритм

Всё на `clamp()`, ручных брейкпоинтов минимум:
`--h1: clamp(38px, 7.2vw, 92px)` · `--h2: clamp(28px, 4.4vw, 54px)` · `--h3: clamp(18px, 2vw, 22px)` · `--body: clamp(15px, 1.15vw, 17px)`
Поля страницы `--pad: clamp(18px, 5vw, 72px)`, воздух между секциями `--sec: clamp(72px, 11vw, 168px)`.

Служебные подписи: 11–13px, `letter-spacing: .1–.22em`, строчными или капслоком — это «шкала прибора», а не текст.

## Компоненты

- **Кнопка** — прямоугольник без скруглений, заливка акцентом, на ховере выворачивается в контур. Вторичная (`.btn--ghost`) — контур серый, на ховере акцентный.
- **Превью работы** — соотношение 16:10, рамка в волосяную линию, номер слота в углу, вертикальные полосы как кадры плёнки. На ховере рамка становится акцентной и появляется **плейхед** — линия с треугольником, идущая за курсором.
- **Слот** (пустая работа) — та же рамка, но пунктиром, и подпись «слот NN · вставь ролик». Клик по пустому слоту делает короткий сдвиг: сюда нужна ссылка.
- **Услуги** — сетка 2×2, разделённая волосяными линиями (сетка на `gap: 1px` по фону-линии), без карточек в карточках.
- **Процесс** — четыре колонки с линией сверху, линия дорисовывается при появлении в кадре.

## Движение

Движение — часть предложения (человек продаёт моушен), но сдержанное:
таймкод в шоуриле идёт 24 кадра/сек · бегущая строка программ 46 сек на цикл · секции всплывают на 22px · плейхед за курсором.
Всё под `prefers-reduced-motion: reduce` выключается.

## Запрещено

- Фиолетовые и сине-фиолетовые градиенты, стеклоблюр без причины, карточки внутри карточек.
- Скругления больше 0 (кроме круглой кнопки play) — язык интерфейса здесь прямоугольный.
- Больше одного акцентного цвета; акцент в качестве фона больших площадей.
- Самохостинг видео: ролики только внешними плеерами, у нас — превью и `iframe` по клику.
- Эмодзи в интерфейсе.
