# Codex и Claude — работа на двух компьютерах

Решение Михаила, 22.09.2026: вся творческая деятельность закреплена за Codex/Astra.
Claude работает у Андрея. Пароли и авторизация между компьютерами не передаются.

| Работа | Ответственный | Отчёт |
|---|---|---|
| Идея, визуальный стиль, тексты, дизайн, презентация, видео | Codex/Astra | Что показано и что утвердил Михаил |
| Растровые изображения | Codex с доступным генератором | Файл, способ генерации, согласованные расходы |
| Реализация, интеграции, исправления | Codex/Astra | Изменённые файлы, реальные команды и результаты тестов |
| Требования, логика, контракты, безопасность, пограничные случаи | Claude | Дефект, доказательство в файле, рекомендация |
| Предложения дополнительных тестов | Claude | Список сценариев, без заявления об их выполнении |
| Запуск тестов, осмотр экрана и итоговая сборка | Codex/Astra | Проверено / не проверено / блокировки |
| Дизайн, затраты и публикация | Михаил и Андрей | Решение людей |

Это рабочее разделение по предпочтениям Михаила, не рейтинг интеллекта моделей.
Claude не рисует и не переписывает творческую часть. Codex не заменяет отсутствующий
генератор растровых изображений SVG или программным рисунком. Платная генерация
требует отдельного согласия с ценой и количеством. Для дизайна сохраняются правила
референсов и показа одного экрана до полной сборки.

## Как устроен новый скрипт

`team_bridge.py` использует только стандартную библиотеку Python 3.10+.
Ничего не устанавливает, не меняет входы, не открывает порты, не получает удалённый
доступ, не публикует код. Скрипт не заменяет приложение Codex и его генератор изображений.

1. Codex в своём окне выполняет задачу. Команда `prepare` собирает только явно
   выбранные текстовые файлы и задачу в `request.json`. Весь проект не копируется.
2. Михаил передаёт пакет Андрею существующим способом передачи файлов.
3. Андрей запускает `start-andrey.ps1` рядом с пакетом. Claude получает только
   текст пакета через стандартный ввод, без инструментов чтения/записи/команд.
   Авторизация используется на машине Андрея; аккаунт не выходит после работы.
4. Андрей возвращает созданный `review-*.json`. Команда `check` сверяет идентификатор
   пакета и содержимое текущих исходников. Устаревший отчёт не принимается.
5. Codex в том же окне читает отчёт, проверяет замечания и исправляет подтверждённое.
   После изменения кода создаётся новый пакет; до двух циклов, затем решение человека.

Для творческой задачи передаются только технические файлы для проверки: Claude
не получает право одобрять художественное решение. Приёмку изображений делает Codex/человек.

## Андрею — запуск

На его компьютере нужны Python 3.10+ и Claude Code с действующим входом через подписку.
Распаковать комплект, положить `request.json` рядом со скриптом.
В Проводнике открыть эту папку, нажать адресную строку, написать `powershell` и Enter.
В открывшееся окно вставить:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start-andrey.ps1
```

Путь здесь относительный только потому, что окно открыто непосредственно в распакованной
папке. Установку и вход не прячем в скрипт. Если входа нет, Андрей запускает `claude auth login`
сам в своём обычном терминале и проходит вход. Скрипт не просит присылать код/пароль.

## Ограничения и проверка

- Перед передачей человек проверяет содержимое `request.json`: фильтр имён и нескольких
  форматов секретов не способен распознать любую конфиденциальную информацию.
- PASS — только результат статического анализа выбранного текста. Это не подтверждение
  прогона тестов, качества изображения или готовности всего продукта к публикации.
- Хеш связывает отчёт с пакетом и ловит устаревшие файлы, но не является электронной подписью.
- Внешние сервисы получают переданный текст; запросы расходуют лимиты подписки Claude.
- Пересылка файлов пока ручная. Автоматическая синхронизация между компьютерами не настроена.
- Настоящий запуск Claude на компьютере Андрея ещё не проверен. Локальные проверки с
  подставными ответами не доказывают доступность модели и совместимость его версии CLI.
- Таймаут ожидания Claude — 5 минут. При таймауте результат не принимается; на Windows
  дочерний процесс CLI может требовать ручного завершения в своём терминале.
- Старые `review-loop.ps1` и `andrey-one-time-test.ps1` — прежний сценарий одного компьютера;
  для нового сценария не используются.
