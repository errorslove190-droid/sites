Два видео с экрана

Без лица, голос поверх экрана. Первое — 5 минут, второе — 10–12 минут. Читай с телефона, записывай на компьютере. Ошибся — не останавливай запись, скажи «ещё раз» и повтори фразу, вырежем.

0. Подготовка (один раз, 30 минут)

1
Программа записи: OBS Studio, бесплатно
obsproject.com → установить → «Источники» + «Захват экрана». Настройки → Вывод: 1080p, 30 кадров, MP4. Микрофон: любой, наушники с микрофоном лучше встроенного в ноутбук. Проверить 10-секундной пробой: голос слышно, экран не дёргается.
2
Чистый экран
Отдельная учётка Windows или хотя бы: скрыть значки рабочего стола, закрыть Telegram и всё лишнее, убрать уведомления (режим «Не беспокоить»), обои однотонные. Масштаб Windows 125–150 %: с телефона мелкий текст не читается.
3
Терминал и браузер крупно
В окне Claude Code шрифт 16–18. В браузере Ctrl и «+» до 125 %. Окна на весь экран, без двух окон рядом.
4
Чистая установка для видео 1
Перед записью удалить: папку claude-work с рабочего стола, четыре ярлыка, ~\.claude\skills (сделай копию на всякий). Иначе установщик напишет «уже есть» и видео не покажет магию. Я подготовлю команду отката, которая всё это вернёт.
5
Скорость
Установка и сборка сайта занимают минуты ожидания. Ничего не говорить в паузах: их вырежем и ускорим в 8 раз с подписью «ускорено». Просто молчи, пока идёт.
Голос: спокойно, как объясняешь другу за соседним столом. Не «приветствую, друзья», не «в этом видео мы». Короткие фразы. Пауза перед каждым действием на секунду, потом действие.

Видео 1 · «Установка за 5 минут»

Цель: покупатель видит, что три шага и правда три. Хронометраж после монтажа 4–5 минут.

0:00 Заставка (монтаж, без голоса)

Чёрный экран, белым Unbounded: «claude-site-kit · Установка». 3 секунды. Сделаю я.

0:03 Что нужно до установки

Экран: открытая консоль. По очереди набираешь четыре команды.
говоришьПеред установкой на компьютере должны стоять четыре вещи. Проверяем.
делаешьclaude --version → Enter → node -v → python --version → git --version
говоришьClaude Code, Node, Python и Git. Если какой-то команды нет, ссылки на установку в README, это минут десять. У меня всё есть, идём дальше.

0:40 Папка

делаешьОткрыть проводник, диск C, показать папку C:\claude-kit с распакованным набором.
говоришьАрхив распакован в папку без русских букв в пути. Это важно: кириллица в пути ломает скрипты. C, claude-kit — нормально. Рабочий стол с русским именем пользователя — нет.

1:00 Установщик

делаешьДвойной клик по setup.cmd. Появляется окно. Вводишь имя, Telegram, логин GitHub.
говоришьОдин файл. Спросит, как к тебе обращаться, твой Telegram для подписи на сайтах и логин GitHub для ссылок. Дальше всё сам: рабочая папка, база знаний, сорок скилов, ярлыки.
Молчишь, пока идёт. Это 2–4 минуты, вырежем.

1:40 Что появилось

делаешьСвернуть консоль. Показать четыре ярлыка на рабочем столе. Открыть claude-work, показать две папки и CLAUDE.md.
говоришьЧетыре ярлыка. «Claude» — основной. «Claude бесплатный» — когда лимит подписки кончился. «Claude на телефон» — управлять с телефона. «Запуск ботов» — ассистент в Telegram, его настроим отдельно. И рабочая папка: правила для Claude и база знаний, которую он читает перед каждой задачей.

2:30 Первый запуск

делаешьЯрлык «Claude» → вопрос про доверие к папке → Yes. Печатаешь: прочитай СТАРТ.md и скажи, какие скилы и заметки ты видишь
говоришьПервый запуск спросит, доверяешь ли ты папке. Да. И контрольная фраза: прочитай СТАРТ и скажи, что видишь.
Ждёшь ответ Claude, он перечисляет разделы. Показать, что в списке есть Ниши, Стили, Клиенты.
говоришьВидит базу, видит скилы. Всё встало. Установка закончена. Дальше — первый сайт, это второе видео.

4:30 Концовка (монтаж)

Чёрный экран: «Следующее видео: сайт за вечер». 3 секунды.

Видео 2 · «Сайт кафе от пустой папки до ссылки»

Цель: покупатель видит весь путь, включая то, что Claude сначала спрашивает и показывает вариант, а не штампует. Реальное время 30–40 минут, после монтажа 10–12. Кафе берём вымышленное, чтобы не светить чужой бизнес: «Кофейня „Тёплый“, Казань, ул. Баумана 12».

Данные кафе (держи рядом)

Кофейня «Тёплый»
Казань, ул. Баумана, 12
+7 900 000-00-00
Пн–Вс 8:00–22:00
Кофе, завтраки, десерты, своя выпечка
Рейтинг 4,8, 214 отзывов (демо)

Что должно быть на экране до записи

Открыт Claude в claude-work. Открыт браузер на пустой вкладке. GitHub Pages уже подключён (docs/06), иначе ссылки не будет.

0:00 Заставка (монтаж)

«claude-site-kit · Сайт за вечер».

0:03 Постановка

говоришьЗадача: сайт для кофейни. У меня есть адрес, телефон, часы и что они продают. Фото пока нет, будут от клиента. Смотри, как это делается с набором.

0:20 Бриф и стиль

делаешьОткрыть в проводнике 1. Моя папка\Ниши, показать список. Открыть «Кафе и рестораны», проскроллить. Открыть Стили, показать «01 Тёмный люкс».
говоришьВ базе десять брифов по нишам. Кафе есть. Внутри — какие секции, что продаёт, какой тон, какие цвета. И пять готовых стилей. Для вечерней кофейни беру «Тёмный люкс». Мне не нужно придумывать дизайн, он уже описан.

1:10 Запрос

делаешьВ Claude печатаешь (можно скопировать):
Собери сайт для кофейни «Тёплый» по брифу «Кафе и рестораны» в стиле «01 Тёмный люкс». Данные: Казань, ул. Баумана 12, +7 900 000-00-00, Пн–Вс 8:00–22:00, кофе, завтраки, десерты, своя выпечка. Рейтинг 4,8, 214 отзывов. Фото пока нет, это демо.
говоришьОдна фраза. Название, бриф, стиль, данные. Никаких промптов на страницу.

1:40 Claude показывает первый экран

Claude по правилу style-lab сначала соберёт hero и покажет. Ждёшь молча (вырежем). Когда покажет ссылку или откроет в панели браузера:
говоришьВидишь, он не делает весь сайт сразу. Сначала первый экран: посмотри, нравится ли. Это экономит лимит: если стиль не тот, меняем сейчас, а не после часа работы. Мне нравится, говорю «да».
делаешьПечатаешь да, собирай остальное

3:00 Сборка (ускорить в монтаже)

Молчишь. Claude собирает секции, публикует. Это 10–20 минут реального времени. В монтаже ускорим до 30 секунд с подписью.

3:30 Результат

делаешьОткрыть ссылку в браузере. Проскроллить сверху вниз медленно. Нажать F12 → Ctrl+Shift+M (режим телефона), проскроллить ещё раз.
говоришьГотово. Первый экран, о месте, меню тизером без выдуманных цен, отзывы настоящей цифрой, контакты с кнопкой позвонить. Смотрим с телефона, потому что владелец откроет ссылку именно с него. Внизу плашка «демо» и моя подпись. Ни одной выдуманной детали: где данных не было, Claude оставил честные заглушки.

5:00 Проверка

делаешьПечатаешь /impeccable critique index.html, ждёшь. Потом проверь по чек-листу качества.
говоришьДва скила перед сдачей. Первый смотрит на дизайн глазами критика: шаблонно ли, нет ли признаков ИИ-дизайна. Второй проверяет чек-лист: мобильная без горизонтального скролла, телефон кликабелен, теги для поиска, иконка. Если что-то нашлось, говорю «исправь».

7:00 Ссылка клиенту

делаешьОткрыть 1. Моя папка\Клиенты\Сообщения клиенту.md, показать шаблон 1. Или спросить Claude: дай строку для СМС клиенту.
говоришьДальше эту ссылку отправляю владельцу. Шаблон сообщения тоже в базе: короткое, без продажи, «собрал черновик, гляньте, завтра наберу». Скрипт звонка там же. Дальше по конвейеру: понравилось — счёт, предоплата, доработка на его фото.

8:30 Счёт

делаешьПечатаешь выстави счёт для кофейни «Тёплый»: разработка сайта, 30000. Открыть готовый HTML, Ctrl+P, показать одну страницу.
говоришьСчёт одной фразой. Реквизиты вписываются один раз в скил, дальше Claude их помнит. Одна страница, сохраняем в PDF, отправляем.

9:30 Итог

говоришьЧто было: адрес, телефон и часы. Что стало: сайт по ссылке, проверенный, с сообщением клиенту и счётом. Один вечер. И так с любой нишей из десяти: меняется бриф и стиль, процесс тот же. Маршрут на первые две недели, от установки до первого заказа, лежит в docs/08.
