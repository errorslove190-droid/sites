# Библиотека вкуса (личная)

Каталог референсов: скриншот сайта → семья стиля → словарь приёмов → готовый бриф для промпта.

- Кинуть скриншоты в `screens/` → сказать Claude «разбери библиотеку».
- Локально: `node server.js` → http://localhost:4701
- Опубликовано: https://errorslove190-droid.github.io/sites/taste/

`data/metadata.json` — описания (правит Claude), `data.json` — собранная копия для GitHub Pages (`node build.js`).

Прогонная библиотека Матвея живёт отдельно: `Desktop/Прогон antislop/библиотека-вкуса/`, порт 4700. Не смешивать.
