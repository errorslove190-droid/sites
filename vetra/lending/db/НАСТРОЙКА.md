# Как включить базу Ветры — 10 минут, без домена и без денег

Домен не нужен: сайт живёт на GitHub Pages, база — в Supabase.
Оба адреса выдаются автоматически.

---

## Шаг 1. Завести проект Supabase

1. Открыть https://supabase.com → **Start your project** → войти через GitHub.
2. **New project**:
   - Name: `vetra`
   - Database Password — придумать и **сохранить у себя** (в чат не присылать).
   - Region: `Frankfurt (eu-central-1)` — ближайший к России.
3. Нажать **Create new project** и подождать ~2 минуты, пока поднимется.

## Шаг 2. Создать таблицы

1. В левом меню — **SQL Editor** → **New query**.
2. Открыть файл `db/schema.sql` из этой папки, скопировать всё целиком, вставить в окно.
3. Нажать **Run** (или Ctrl+Enter). Должно написать `Success`.

## Шаг 3. Вписать ключи в сайт

1. Левое меню → **Project Settings** (шестерёнка) → **API**.
2. Скопировать два значения:
   - **Project URL** — вида `https://abcdefgh.supabase.co`
   - **anon public** — длинная строка, начинается на `eyJ...`
3. Открыть файл `js/vetra-config.js` и вставить их вместо заглушек.

> Эти два значения — публичные, их видно в коде страницы, так и задумано.
> Ключ **service_role** с той же страницы не трогать и никуда не вставлять.

## Шаг 4. Письмо должно присылать код, а не ссылку

Формы входа сделаны под шестизначный код. По умолчанию Supabase шлёт ссылку.

1. Левое меню → **Authentication** → **Emails** → шаблон **Magic Link**.
2. Заменить содержимое письма на что-то такое:

```html
<h2>Код для входа в Ветру</h2>
<p>Ваш код: <b style="font-size:22px; letter-spacing:3px">{{ .Token }}</b></p>
<p>Код действует один час. Если вы не запрашивали вход — просто удалите письмо.</p>
```

Главное — чтобы в письме был `{{ .Token }}`, а не `{{ .ConfirmationURL }}`.

3. Там же → **Authentication → URL Configuration → Site URL** вписать
   `https://errorslove190-droid.github.io/sites/vetra/lending/`

## Шаг 5. Проверить

1. Закоммитить и запушить изменения, дождаться публикации GitHub Pages.
2. Открыть `.../vetra/lending/index.html`, внизу оставить заявку на своё имя.
3. В Supabase → **Table Editor** → таблица `leads` — строка должна появиться.
4. Открыть `login.html` → вкладка **Регистрация** → своя почта → письмо с кодом →
   ввести код → должен открыться `app.html` с вашим именем.
5. Supabase → **Authentication → Users** — там появится ваш пользователь,
   а в **Table Editor → profiles** — имя и компания.

## Что нужно знать про бесплатный тариф

- **Письма.** Встроенная почта Supabase шлёт около 2–4 писем в час и часто
  попадает в «Спам». Для себя и первых пилотов хватит. Когда пойдут живые
  клиенты — подключить свой SMTP (Authentication → SMTP Settings);
  бесплатные варианты: Resend, Brevo, Unisender.
- **Простой.** Если в базу два месяца никто не заходит, проект засыпает —
  будится одной кнопкой в панели.
- **Заявки.** Смотреть в Table Editor → `leads`. Оттуда же выгрузка в CSV.
  Уведомления в Telegram — отдельный шаг, пока их нет.
- **Оплата.** Страница `checkout.html` сейчас не берёт деньги: она оставляет
  заявку на подключение. ЮKassa подключается отдельно и требует ИП или юрлицо.

## Что где лежит

| Файл | За что отвечает |
|---|---|
| `js/vetra-config.js` | адрес базы и публичный ключ |
| `js/vetra-db.js` | все обращения к базе в одном месте |
| `js/vetra-auth.js` | вход и регистрация на `login.html` |
| `js/vetra-lead.js` | приём заявок с любой формы `data-lead="…"` |
| `js/vetra-app.js` | охрана кабинета `app.html`, имя в шапке |
| `db/schema.sql` | таблицы и правила доступа |
