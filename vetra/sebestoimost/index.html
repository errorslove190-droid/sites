3. По каналам: что стоит нам и что клиент платит площадке

Главное открытие этого раздела: прямых денежных расходов на канал у нас нет ни по одному из них. API Telegram, ВКонтакте, MAX и почты бесплатны. Там, где площадка берёт деньги (Авито, WhatsApp, Wildberries, Ozon), она берёт их с клиента на его аккаунте, мимо нас. Наша себестоимость канала — это часы на подключение, разбор ошибок и поддержку.

Для второго шага это значит: ценник на канал не может опираться на «нам он дорого обходится». Он опирается на ценность канала для клиента и на часы подключения. И у каждого платного канала на ценнике честно пишем: «плюс столько-то площадке, не нам».

6. Что из этого следует для второго шага

  1. Сервер — единственная крупная переменная. Без него клиент обходится нам в сотни рублей, с ним — больше тысячи. Значит «свой сервер каждому» либо стоит отдельной строкой в ценнике, либо входит только в дорогие внедрения.
  2. Каналы для нас бесплатны, поэтому ценник на канал — это ценность и часы, а не расходы. На ценнике платного канала пишем две суммы: нам и площадке.
  3. ИИ-автоответ — самая дешёвая дорогая опция. Себестоимость 82–574 ₽, продавать можно кратно дороже, маржа около 90 %.
  4. Постоянные 25 тыс ₽ в месяц никуда не деваются. При пяти клиентах на каждого ложится 5 000 ₽ в месяц; подпиской 1 500 ₽ это не закрыть, закрывает только разовое внедрение. Это и есть довод за «Ветра Премиум».
  5. Чего не хватает, чтобы цифры стали фактами: точная цена SpeechKit из калькулятора Yandex Cloud · часы поддержки одного клиента · часы внедрения по чек-листу · связь.
