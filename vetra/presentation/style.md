# Ветра — презентация продукта для партнёра

Продолжение утверждённого стиля 01 из ../echomind/style.md. Не редизайн продукта.
Кремовый #f8f5ed, чернила #0a1020, голубой #dce8ff, синий #2c78d5; текст ссылок #1f63bc.
Локальный Google Sans с кириллицей из ../maket/fonts/. Бренд только «Ветра».
Режим: просмотр продукта. Главные доказательства — реальные снимки интерфейсов; не декоративные макеты.
11 разделов: продукт, лендинг, вход, администратор, руководитель, настройка, видео, готовность, связка EchoMind, пилот, следующий шаг.
Обычная вертикальная страница и отдельный режим показа по одному слайду. На телефоне вертикальное чтение. Любой снимок увеличивается.
Регистрация — макет, остальные панели — локальная версия на синтетических данных. Пилот и интеграция не объявляются запущенными. Ролик — черновик с устаревшими обещаниями, предупреждение обязательно.
Существующие страницы и ролики не меняем. Без внешних скриптов, новых шрифтов и платной генерации.
