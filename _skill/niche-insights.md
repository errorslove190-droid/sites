# Инсайты по нишам — боли клиентов и свободные углы

Кеш исследований ниш для конвейера лидов. Ниша исследуется ОДИН раз, запись переиспользуется для всех лидов этой ниши. Запись живёт ~6 месяцев, потом освежить.

Формат записи:

```
## {Ниша} — {Город} (исследовано {дата})
**Боли клиентов (их голосом):** 3–5 пунктов цитатами/перефразом из отзывов
**Штампы конкурентов (избегать):** что у всех сайтов одинаково
**Свободные углы:** что никто не обещает, а клиенты просят
**Выводы для черновика:** какие блоки/акценты закрывают эти боли
```

---

Записей пока нет. Первые кандидаты (топ-ниши из [[Стратегии поиска клиентов]]): ремонт квартир, мебель на заказ, автосервисы — по Казани.
