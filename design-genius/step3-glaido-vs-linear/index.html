#1The three largest gaps

GAP 01

Letter spacing is too loose

Glaido's display line sits at −0.76px on 76px type (−0.010em). Linear tracks −0.022em at display sizes — that's −1.67px on the same type. Loose tracking is why the hero reads airy instead of engineered.

GAP 02

There is no elevation ladder

Glaido builds panels from white washes — rgba(255,255,255,.03/.05/.1) on one canvas. Linear climbs a real ladder: #08090a → #0f1011 → #161718 → #23252a, edged with 0.5px hairlines. Surfaces need addresses, not opacity.

GAP 03

The accent is everywhere

Lime appears on 117 elements of the Glaido homepage — text, chips, fills. Linear allows its acid lime exactly one filled action per view. When everything signals, nothing does.

#8Design decisions

01

Glaido now

Lime lives on 117 elements — headings, links, chips, fills — so the eye stops ranking it.

Change to

One filled lime CTA per view. Demote every other lime to grey text (#8A8F98) or a neutral pill rgba(255,255,255,.05).

02

Glaido now

Display type at weight 400, −0.010em. The headline floats loose above the fold.

Change to

Track display type to −0.022em and lift weight into the 510–590 band. Tight and mid-weight reads engineered, not shouted.

03

Glaido now

Panels are white washes (.03/.05/.10) on one canvas — no addressable layers.

Change to

Adopt a named ladder — #0D0D0D → #141516 → #1B1C1E — and edge cards with 1px inset #23252A instead of opacity.

04

Glaido now

Eight border radii from 2px to 33,554,400px across buttons, chips and cards.

Change to

Cut to three: 6px controls, 12px cards, 9999px pills. Refactor every corner to the nearest of the three.

05

Glaido now

CTA is a lime rectangle at 2px radius, weight 400 — the sharpest and loudest object on the page.

Change to

6px radius, weight 510, −0.011em, padding 10×16 — Linear's exact button recipe, in Glaido's own lime.
